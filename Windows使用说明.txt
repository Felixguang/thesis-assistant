==========================================================
商务英语毕业论文助手 - Windows 使用说明
==========================================================

【启动方法】
1. 双击 "启动.cmd"  （推荐）
2. 或双击 "启动.bat"  （要求 venv 已装好）
3. 或双击 "run.bat"   （自动检测环境）

【如果双击后黑框闪退，看不见任何错误】

方法 A：手动打开 cmd 运行
  1. 在 _prototype 文件夹空白处按住 Shift + 右键
  2. 选择 "在此处打开命令窗口" / "Open PowerShell window here"
  3. 输入：启动.cmd
  4. 现在能看到完整错误信息了

方法 B：用 cmd /c 强制运行
  Win+R  → 输入：cmd /c "cd /d D:\path\to\_prototype && 启动.cmd"

【最常见的 5 种打不开原因 + 解决】
==========================================================

1. 没装 Python
   表现：黑框闪退，cmd 中显示 'python' 不是内部或外部命令
   解决：
     - 下载 https://www.python.org/downloads/windows/
     - 安装时务必勾选 "Add Python to PATH"
     - 重启电脑后再双击启动.cmd

2. 缺 tkinter
   表现：报错 "ModuleNotFoundError: No module named '_tkinter'"
   解决：
     - 重新运行 Python 安装包，选 "Modify"
     - 勾选 "tcl/tk and IDLE" 选项
     - 点击 "Install Now" 完成

3. 文件被 Word 占用
   表现：能启动 GUI，但选 .docx 文件时崩溃
   解决：关闭所有 Word 窗口重试

4. 文件夹路径有中文/空格
   表现：偶尔报错，错误信息奇怪
   解决：把 _prototype 文件夹移到 C:\thesis\ 这种纯英文路径下

5. Windows 安全策略阻止 bat 运行
   表现：双击 bat 毫无反应，连闪退都没有
   解决：
     - 打开"Windows Defender 安全中心" → "病毒和威胁防护"
     - "病毒和威胁防护设置" → "管理设置"
     - 关闭 "实时保护"（临时）
     - 或：右键 bat 文件 → 属性 → 勾选 "解除锁定" → 确定

==========================================================
【手动装依赖的方法】
==========================================================

如果启动.cmd 在创建 venv 阶段失败，可以手动：

  1. Win+R 输入 cmd
  2. cd /d D:\path\to\_prototype
  3. python -m venv venv
  4. venv\Scripts\activate
  5. pip install -r requirements.txt
  6. python app.py

成功后下次直接双击 启动.cmd 即可。
