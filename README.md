# 商务英语毕业论文助手

仲恺农业工程学院外国语学院 · 商务英语专业 · 本科毕业论文辅助工具（v0.3）

---

## 这是什么

一个**纯本地运行**的桌面工具，帮商务英语专业本科生解决选题与格式两大难题：

| Tab | 功能 |
|---|---|
| 🎯 **选题建议** | 输入候选题目，分析撞题风险、理论框架、方向热度、改进建议 |
| 📚 **选题库浏览** | 浏览 **879 条** 2019-2026 届往届真实选题，按方向/年份筛选 |
| 📋 **格式检查** | 按学院规范逐项检查论文 `.docx`，80+ 条规则，覆盖封面/扉页/承诺书/摘要/目录/正文/参考文献/附录/致谢/页码/图表/引用 |

外加一个**导入选题**功能（支持 xls/xlsx），方便老师把新数据导入库（入口在「选题库浏览」tab 左侧）。

---

## 特点

- ✅ **零网络、零成本**：所有处理在本地完成，不上传论文
- ✅ **真实数据**：内置 879 条 2019-2026 届真实选题（不含学生姓名）
- ✅ **规范精准**：检查规则全部来自学院《毕业论文（设计）格式规范（2025-12 修订）》
- ✅ **跨平台**：macOS / Windows / Linux 均可运行
- ✅ **跨 DPI 自适应**：窗口按物理 cm 计算（默认 26×19cm），字号/按钮/行高按 DPI 缩放，Retina/4K 不显小
- ✅ **零 Python 也能用**：打包成单 `.exe` / `.app` 后双击即用（见下方"打包"）

---

## 跨平台分辨率自适应

工具启动时自动探测屏幕 DPI：

- **窗口尺寸**按物理 cm 计算（默认 26 × 19 cm，最小 22 × 16 cm），在不同分辨率屏幕上**视觉尺寸一致**
- **字号 / 按钮 / Treeview 行高 / Notebook 标签**按 DPI 缩放
- **macOS Retina** 强制 ≥ 1.25 倍（避免文字偏小）
- **Windows 高 DPI 屏**（150% / 200% 缩放）自动放大窗口和控件

无需手动设置。普通屏（96 DPI）下与原有视觉一致。

## 启动方式

### 方式一：开发者模式（命令行）

需要 Python 3.10+。

```bash
cd _prototype
python3 -m venv venv
source venv/bin/activate       # Windows: venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

或直接用启动脚本：
- macOS / Linux：双击 `启动.command` 或 `run.sh`
- Windows：双击 `启动.cmd` 或 `run.bat`

### 方式二：打包成单文件（推荐给学生）

用户拿到 `.exe` 或 `.app`，**无需安装 Python**，双击即用。

```bash
# macOS
./build_mac.sh
# 产物: dist/商务英语毕业论文助手.app

# Windows
build_windows.bat
REM 产物: dist\商务英语毕业论文助手.exe
```

详见 [Windows使用说明.txt](Windows使用说明.txt)。

#### ⚠️ macOS 首次启动被拦截（Gatekeeper）

打包后的 `.app` **未做 Apple 签名**，首次双击会提示「无法打开，因为它来自身份不明的开发者」。这是 macOS 安全机制，不是 bug。**只需操作一次**，之后双击正常运行。

**方法 1：右键打开（最简单）**

1. 在 Finder 找到 `商务英语毕业论文助手.app`
2. **右键点击**（不要双击）→ 选择「打开」
3. 弹出提示框 → 点击「打开」按钮

**方法 2：系统设置永久放行**

1. 先尝试双击 `.app`（会被拦截）
2. 打开 **系统设置 → 隐私与安全性**
3. 滚到页面最下方，会看到「商务英语毕业论文助手.app 已被阻止打开」
4. 点击右侧的「仍要打开」按钮

**方法 3：命令行清除 quarantine（适合技术老师）**

在终端执行：

```bash
xattr -cr /path/to/商务英语毕业论文助手.app
```

之后双击 `.app` 直接打开，无任何弹窗。

> 💡 **想要彻底解决**（让所有学生零弹窗启动）需要 Apple Developer 账号（$99/年）做代码签名 + 公证。详见 `build_mac.sh` 注释。

## 功能详解

### 🎯 选题建议

1. 在输入框写下候选题目（中文或英文）
2. 点「🔍 分析选题」
3. 看结果（5 段式）：
   - **段 1 专业研究范围**：是否符合本专业 4 大方向（商务环境中的语言研究 / 翻译研究 / 跨文化商务交际 / 商务英语学习与教学），并提示是否体现"商务环境"
   - **段 2 选题聚焦性**：检查理论 + 对象 + 主题三要素齐全程度
   - **段 3 创新性 / 撞题检测**：与库内最像的 5 条往届选题对比，给出风险等级
   - **段 4 字数 & 表达要求**：主标题字数、理论框架表达规范度
   - **段 5 改进建议 + 参考题目**：
     - 列出 **热门理论**（⚠️ 谨慎使用，往届 ≥ 24 次，撞题风险高）
     - 列出 **冷门理论**（✨ 较少使用，可考虑；建议自行寻找合适理论）
     - 按 **方向匹配优先** 推荐 5 条近三年参考题目

### 📚 选题库浏览

- 顶部搜索框：模糊搜索题目关键词
- 方向筛选：只看某个方向（4 大方向 + 其他）
- 年份筛选：默认"全部"显示所有年份
- 关键词热度榜：高频关键词一目了然
- 同一行按钮：**左** `📥 导入选题` / **右** `📄 导出 CSV` + `📊 导出 Excel`

### 📋 格式检查

1. 点「📁 选择文件」选你的论文 `.docx`
2. 点「🔍 开始检查」
3. 看结果：
   - **总体评级** A 优秀 / B 良好 / C 待改进 / D 不合格
   - **问题分类** 高 / 中 / 低 严重度
   - **每条问题**：位置 / 规范要求 / 你的实际情况 / 修改建议
4. 可「导出报告」存为 txt 文件交导师看
5. 可「标注到原文档」自动在 docx 里标注每条问题位置

**检查范围**（80+ 条规则）：

| 区域 | 检查项 |
|---|---|
| 封面 / 扉页 | 学院名称、Supervisor、Guangzhou 字段、四级页 |
| 学生承诺书 | 签名 / 日期 |
| 中文摘要 | 标题"摘 要"格式、关键词 3-5 个（中文分号分隔） |
| 英文摘要 | Abstract 加粗居中三号、Keywords 加粗、英文分号分隔 |
| 目录 | Table of Contents 四号加粗居中、正文小四 1.5 倍行距、Title Case |
| 正文标题 | L1 四号 TNR 加粗 / L2 小四 TNR 加粗 / L3 小四 TNR 不加粗、Title Case、章节另起页 |
| 正文图表 | 图题/表题五号 TNR 居中、Example 例证 |
| 正文引用 | 上标引用率 ≥30% |
| 参考文献 | Bibliography 五号 TNR、12 种类型格式、末尾英文句号 |
| 致谢 | Acknowledgements 四号加粗居中 |
| 页码 | 目录罗马数字 / 正文阿拉伯数字 |

## 已知局限

- 中文分词使用商务英语领域词典，未登录词按单字处理
- 字号判定依赖 docx 内嵌的字号信息，WPS 写入的某些格式可能识别不出
- 格式检查只查**格式问题**，不查内容、错别字、英文语法
- 不查重、不调大模型（保持零网络）
- 章节标题识别按仲恺商英规范约束（L1 编号 1-4，L2/L3 编号 1-9）；其他学校可能需要放宽
