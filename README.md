# 商务英语毕业论文助手（本地版）

仲恺农业工程学院外国语学院 · 商务英语专业 · 毕业论文辅助工具

## 这是什么

一个**纯本地运行**的桌面小工具，帮商务英语专业本科生解决两个最头疼的问题：

1. **🎯 选题建议**：输入候选题目，告诉你撞题风险、理论框架、方向热度
2. **📋 格式检查**：把你的论文 docx 拖进来，按学校规范逐项检查格式

外加一个**📚 选题库浏览**功能，可以翻阅 184 个往届真实选题找灵感。

## 特点

- ✅ **零网络、零成本**：所有处理在本地完成，不上传论文
- ✅ **零额外依赖**：只用 Python 自带库 + python-docx + openpyxl（这两个 macOS 自带或一条命令装）
- ✅ **真实数据**：内置 184 个 20-22 级真实选题 + 1 篇优秀论文样本
- ✅ **规范精准**：检查规则全部来自学院《毕业论文（设计）格式规范（2025-12 修订）》

## 使用说明

### 🎯 选题建议

1. 在输入框写下你的候选题目（中文或英文都行）
2. 点「🔍 分析选题」
3. 看结果：
   - **风险等级** 🔴🟡🟢：越高越需要改
   - **关键词提取**：自动从题目里抓核心概念
   - **理论框架识别**：看你有没有明确的研究视角
   - **方向热度**：参考往届有多少人选了类似方向
   - **撞题检测**：和你库里最像的 5 个往届选题
   - **改进建议**：具体怎么改（换理论 / 换案例 / 缩小范围）

### 📋 格式检查

1. 点「📁 选择文件」选你的论文 docx
2. 点「🔍 开始检查」
3. 看结果：
   - **总体评级** A/B/C/D
   - **问题分类** 高/中/低 严重度
   - **每条问题**：位置、规范要求、你的实际情况、修改建议
4. 可以「导出报告」存为 txt 文件交导师看

### 📚 选题库浏览

- 顶部搜索框：模糊搜索题目关键词
- 方向筛选：只看某个方向（如翻译策略、跨文化）
- 点任一条目看详情（含关键词、英文标题）

## 检查规则覆盖范围

| 类别 | 规则 |
|---|---|
| **页面** | A4、页边距 2.4cm、无页眉 |
| **段落** | 1.5倍行距、首行缩进 |
| **字体字号** | 正文宋体/Times New Roman 小四号 |
| **标题层级** | 一级 Times New Roman 四号加粗 / 二级小四加粗 / 三级小四 |
| **摘要** | 中英文摘要、关键词 3-5 个 |
| **目录** | Table of Contents 必需 |
| **参考文献** | ISO 690 风格、不少于 15 篇 |
| **图表** | Diagram/Table 编号、五号字、三线表 |
| **结构完整性** | 封面→扉页→承诺书→摘要→目录→正文→参考文献→致谢 |

## 已知局限

- 中文分词使用商务英语领域词典（60+ 词），未登录词按单字处理。如发现分词不准可手动加进 `DOMAIN_DICT`
- 字号判定依赖 docx 内嵌的字号信息，如果论文是用 WPS 写入的某些格式可能识别不出
- 格式检查只查**格式问题**，不查内容、错别字、英文语法
- 暂时不查重（需对接外部数据库）
- 暂时不调大模型做润色（避免网络依赖）
